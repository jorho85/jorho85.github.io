MAT 171 / Precalculus Algebra

Exponents and Logarithms

Evaluate powers, read a logarithm as an exponent, and use both to solve equations.

Use the arrow keys to advance and reveal answers.

Plan for about 50 minutes. Allow 6 minutes for review, 8 for the inverse relationship and domain, 12 for properties and change of base, 17 for solving equations, and 5 for the exit ticket. Use the substitution example and the population model as time allows.

The first answer is 3. Have students bracket the second answer between 2 and 3 because 4 < 7 < 8. A logarithm gives a name to that exact input.

03 / Logarithms

A logarithm answers “what exponent?”

\(\log_b A=c\quad\Longleftrightarrow\quad b^c=A\)

Base \(b>0\) with \(b\ne1\), argument \(A>0\), and output \(c\in\mathbb R\).

Read the equation both ways

\(\log_2 8=3\) because \(2^3=8\).

\(\log_2 7\) is the exponent on \(2\) that gives \(7\).

Try it

Evaluate \(\log_3(1/9)\).

\(\log_3(1/9)=-2\) because \(3^{-2}=1/9\).

Ask students to point to the base, argument, and output in each form. Emphasize that a log can have a negative output even though its argument is positive. For a quick follow-up ask for log base 9 of 3.

04 / Inverse functions

The input and output swap

\(y=2^x\)
Domain \(\mathbb R\), range \((0,\infty)\)
\(y\)-intercept \((0,1)\), asymptote \(y=0\)
\(y=\log_2 x\)
Domain \((0,\infty)\), range \(\mathbb R\)
\(x\)-intercept \((1,0)\), asymptote \(x=0\)
Inverse identities
\(\log_b(b^x)=x\) for every real \(x\)
\(b^{\log_b A}=A\) for \(A>0\)
Ask which exponential feature becomes the vertical asymptote of the logarithm. Both curves shown are increasing because the base is 2. With a base between 0 and 1 the two inverse curves are both decreasing and keep their respective domains and ranges.

05 / Notation and domain

Read the base and check the argument

Common and natural logarithms

\(\log x=\log_{10}x\), so \(\log(1000)=3\).

\(\ln x=\log_e x\), so \(\ln(e^{-2})=-2\).

Which inputs are allowed?

Find the domain of \(h(x)=\ln(2x-6)\).

\(2x-6>0\Rightarrow x>3\). The domain is \((3,\infty)\).

Every real logarithm needs a positive argument. In particular, \(\log_b 0\) is undefined.

Ask students whether x = 2 is allowed in the example. The input to the whole function is positive, but the expression inside the log is negative. Also point out that solving equations later will require checking every original argument.

06 / Logarithm properties

Products, quotients, and powers

Use a common base \(b>0\), \(b\ne1\), with \(M,N>0\).

RuleIdentityExample
Product\(\log_b(MN)=\log_b M+\log_b N\)\(\log_2(4\cdot8)=2+3=5\)
Quotient\(\log_b\!\left(\dfrac MN\right)=\log_b M-\log_b N\)\(\log_2(8/4)=3-2=1\)
Power\(\log_b(M^r)=r\log_b M\)\(\log_2(4^3)=3\cdot2=6\)

Test addition. \(\log_2(4+4)=3\), while \(\log_2 4+\log_2 4=4\).

Derive the product rule by writing M=b^m and N=b^n. Their product is b^(m+n), so its logarithm is m+n. Ask which exponent rule corresponds to each other row. Have students explain the addition counterexample before advancing.

07 / Practice with properties

Expand one logarithm

Assume \(x>0\) and \(y>0\). Expand and simplify.

\(\displaystyle\log_3\!\left(\frac{9x^2}{\sqrt y}\right)\)

\(\displaystyle\log_3(9x^2)-\log_3(y^{1/2})\) by the quotient rule

\(\displaystyle\log_3 9+2\log_3 x-\tfrac12\log_3 y\) by the product and power rules

\(\displaystyle 2+2\log_3 x-\tfrac12\log_3 y\) since \(3^2=9\)

Give students a minute to choose the first operation. Ask what sign the logarithm of the denominator should get. The positivity assumptions let us expand log of x squared as 2 log x without changing the allowed inputs under those assumptions.

08 / Practice with properties

Condense several logarithms into one

Use the original domain \(x>0\).

\(2\ln x+\ln(x+1)-\ln 4\)

Move the coefficient into the exponent

\(\ln(x^2)+\ln(x+1)-\ln 4\)

Combine using multiplication and division

\(\displaystyle \ln\!\left(\frac{x^2(x+1)}4\right),\quad x>0\)

Test \(x=-\tfrac12\). The condensed formula accepts it, but the original term \(\ln x\) excludes it. Keep \(x>0\).

Ask which rule they must reverse first. The condensed formula alone is defined for some negative inputs, so carry the original restriction forward whenever solving an equation.

09 / Change of base

Evaluate a logarithm in any valid base

\(\displaystyle\log_b A=\frac{\ln A}{\ln b}=\frac{\log A}{\log b}\)

Example

\(\displaystyle\log_5 18=\frac{\ln 18}{\ln 5}\approx1.796\)

Check the size. \(5^1<18<5^2\).

Why it works

If \(t=\log_b A\), then \(b^t=A\).

Taking \(\ln\) gives \(t\ln b=\ln A\).

Divide by \(\ln b\).

More generally, \(\log_b A=\frac{\log_c A}{\log_c b}\) for any \(c>0\) with \(c\ne1\).

Recall that the original base b is positive and different from 1. Therefore ln b is defined and nonzero. Have students check the approximation with common logs as well.

10 / Solving equations

Choose a first move

Variable in the exponent

  • Isolate the power.
  • Match bases when possible, then set the exponents equal.
  • Otherwise, take a log of both positive sides.

Variable inside a logarithm

  • Write the restrictions from all original arguments.
  • Isolate or combine logs of the same base.
  • Rewrite in exponential form or equate arguments of equal same-base logs.

One-to-one functions give the same output only when their inputs match. That’s why the same-base steps work.

For b^u=b^v, equate u and v. For log base b of U equal to log base b of V, equate U and V only where both arguments are positive. The case of an isolated power equal to zero or a negative number has no real solution.

11 / Exponential equations

Rewrite both sides with the same base

\(4^{x+1}=8^{2x-1}\)

\((2^2)^{x+1}=(2^3)^{2x-1}\)

\(2^{2(x+1)}=2^{3(2x-1)}\)

\(2x+2=6x-3\quad\Rightarrow\quad x=\dfrac54\)

At \(x=\tfrac54\), both rewritten exponents equal \(\tfrac92\).

Have students suggest a common base before revealing the first line. Use the power-of-a-power rule from the warm-up. Check by substituting x=5/4 into the two exponents after rewriting.

12 / Exponential equations

Isolate the power, then take logs

\(4\cdot3^{2x-1}=28\)

\(3^{2x-1}=7\)

\(\ln(3^{2x-1})=\ln 7\quad\Rightarrow\quad (2x-1)\ln 3=\ln 7\)

\(\displaystyle x=\frac{1+\ln 7/\ln 3}{2}\approx1.386\)

Keep the exact expression until the last step. Here, the power of \(3\) must equal \(7\), between \(3\) and \(9\).

Ask students why the coefficient 4 is divided out before taking logs. The equivalent exact result is (1 + log base 3 of 7)/2. Since 2x−1 is between 1 and 2, x should be between 1 and 1.5.

13 / Logarithmic equations

Rewrite or equate arguments

One isolated logarithm

\(2\ln(x-1)=6\)

Original domain \(x>1\).

\(\ln(x-1)=3\Rightarrow x-1=e^3\).

\(x=1+e^3\) is in the domain.

Equal logarithms, same base

\(\log_4(2x+1)=\log_4(x+5)\)

Both arguments are positive for \(x>-\tfrac12\).

\(2x+1=x+5\Rightarrow x=4\).

Both arguments equal \(9\) at \(x=4\).

Invite students to name the base e on the left. On the right, explicitly intersect the two conditions 2x+1>0 and x+5>0. Both equations have an exact answer without a calculator.

14 / Logarithmic equations

Combine the logs and check both candidates

\(\log_2 x+\log_2(x-2)=3\)

Solve within the original domain

Both arguments must be positive, so \(x>2\).

\(\log_2[x(x-2)]=3\Rightarrow x(x-2)=8\).

\((x-4)(x+2)=0\Rightarrow x=4\) or \(x=-2\).

Check the original equation

At \(x=4\), \(\log_2 4+\log_2 2=2+1=3\).

At \(x=-2\), both original arguments are negative. This candidate is extraneous.

Solution \(x=4\)

Pause after the quadratic roots. At −2 the product equals 8, but the individual factors are −2 and −4. Have students explain how the combined formula can appear valid there while the original equation is undefined.

15 / Partner practice

What does the subtraction become?

\(\log_3(x+9)-\log_3(x-1)=1\)

  1. Write the original domain.
  2. Combine the logarithms.
  3. Solve and check your answer.

The domain is \(x>1\).

\(\displaystyle\log_3\!\left(\frac{x+9}{x-1}\right)=1\Rightarrow\frac{x+9}{x-1}=3\).

\(x+9=3(x-1)\Rightarrow x=6\).

At \(x=6\), both arguments are positive and their ratio is \(3\).

Give pairs about two minutes. Ask which restriction lets them multiply both sides by x−1. To check directly, 15 and 5 are positive and log base 3 of their ratio is 1.

16 / Optional extension

Look for a hidden quadratic

\(4^x-5\cdot2^x+4=0\)

\(4^x=(2^x)^2\). Let \(u=2^x\).

\(u^2-5u+4=(u-1)(u-4)=0\).

\(2^x=1\) or \(2^x=4\), so \(x=0\) or \(x=2\).

An exponential substitution \(u=2^x\) requires \(u>0\).

Use this if time allows. Connect the substitution to factoring quadratics students already know. Ask how they would handle a negative u candidate. Verify both solutions in the original equation.

17 / Application

Use a logarithm to find when

A model for a lab culture is \(P(t)=240(1.5)^t\), where \(t\) is time in hours since the start. When does the model predict \(1{,}000\) cells?

\(240(1.5)^t=1000\quad\Rightarrow\quad (1.5)^t=\dfrac{25}{6}\)

\(\displaystyle t=\frac{\ln(25/6)}{\ln(1.5)}\approx3.520\)

The model reaches \(1{,}000\) cells about \(3.52\) hours after the start.

Let students set up the equation before revealing. Check with P(3)=810 and P(4)=1215, so the answer should fall between three and four hours. This is an illustrative model with continuous time.

18 / Exit ticket

Choose a rule and show your first step

  1. Expand \(\displaystyle \ln\!\left(\frac{4x^3}{y}\right)\) for \(x,y>0\).
  2. Solve \(2^{3x}=11\). Give the exact answer and an approximation to three decimal places.
  3. Solve \(\ln(x-1)+\ln(x-3)=\ln 15\). State the original domain and check your candidates.
Give students four to five minutes before showing the solution. Ask them to label the rule used in the first line of each problem. If time is short, use the third problem as the whole exit ticket.

19 / Exit ticket debrief

Check your steps

1. Expand. \(\ln 4+3\ln x-\ln y\)

2. Take logs. \(3x\ln 2=\ln 11\Rightarrow x=\dfrac{\ln 11}{3\ln 2}\approx1.153\).

3. Combine and check. The original domain is \(x>3\).

\((x-1)(x-3)=15\Rightarrow (x-6)(x+2)=0\).

The domain excludes \(-2\). At \(x=6\), the arguments are \(5\) and \(3\), with product \(15\). So \(x=6\) is the solution.

Ask students to compare their first steps. In the second problem any valid log base gives the same result. In the third, solving the resulting quadratic produces candidates and the original domain decides which to keep.
